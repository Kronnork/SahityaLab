# Changelog

All notable changes to SāhityaLab are documented here.

## [0.1.0] - 2026-11-09

### Added

- Review workspace generation, protocol validation and review-type-specific manuscript outlines.
- CSV, JSON, BibTeX, PubMed MEDLINE and common OpenAlex JSON ingestion.
- Repeatable imported record identifiers, DOI/title deduplication, screening suggestions and reviewer reconciliation.
- Evidence tables, descriptive profiles and optional Excel export.
- PRISMA 2020 flow-count checks and checklist scaffold.
- PyBibX preparation manifest and workbench launch/stop commands.
- DOCX comment extraction with selected-text anchors, optional legacy DOC conversion and LaTeX comment parsing.
- Supervisor-feedback classification and action register.
- Journal response matrix in JSON, CSV and Markdown, with completeness validation.
- Explicit OpenAI-backed supervisor-feedback analysis and journal-response drafting commands.
- MIT license, CI workflow, examples and documentation.
